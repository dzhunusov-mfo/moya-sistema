# Моя система — архитектура

Личная система ведения дневника, трекинга привычек и биометрии с ИИ-командой,
которая анализирует накопленные данные и даёт заключения.

Автор и единственный пользователь: Данияр Жунусов.
Статус: рабочий прототип, используется ежедневно с июля 2026.

## 2. Компоненты

### 2.1 Веб-приложение (фронтенд)

| | |
|---|---|
| Репозиторий | `github.com/dzhunusov-mfo/moya-sistema` |
| Файл | `index.html` — весь код в одном файле (HTML + CSS + JS, без сборки) |
| Хостинг | GitHub Pages: `https://dzhunusov-mfo.github.io/moya-sistema/` |
| Зависимости | нет (только шрифты Google Fonts) |
| Хранение состояния | `localStorage` браузера (черновики, отметки за день, очередь отправки) |

Три вкладки:
- **Дневник** — текст (в т.ч. голосовой ввод клавиатурой iOS) → отправка в лист «рефлексия»
- **Привычки** — чекбоксы по списку привычек → отправка в лист «трекер привычек»
- **ИИ-команда** — кнопка «Разбор» и чат: шесть ролей по очереди анализируют данные

Ключевые константы в коде:
```js
var WEBHOOK   = "https://script.google.com/macros/s/AKfycbzp29-.../exec";
var AI_PROXY  = "https://moya-sistema-ai.dzhunusov-482.workers.dev";
```

Роли ИИ-команды заданы в объекте `ROLES` (системные промпты): Штурман фокуса,
Психолог, Аналитик паттернов, Челленджер, Наставник развития, Хранитель ритуалов.

### 2.2 Google Apps Script (бэкенд)

| | |
|---|---|
| Где живёт | внутри таблицы «Трекинг 3.0» → Расширения → Apps Script |
| В гите | нет (единственная копия — в Google; резервная копия должна лежать в репозитории как `apps-script.gs`) |
| Развёртывание | Веб-приложение, «запуск от моего имени», доступ «Все» |
| Аккаунт-владелец | dzhunusov@gmail.com |

Единый эндпоинт, режим передаётся параметром `mode` (GET или POST):

| mode | Назначение | Параметры |
|---|---|---|
| *(пусто)* | запись в дневник | `text`, `date` (опц., ДД.ММ.ГГГГ) |
| `habits` | запись привычек за день | `date`, `vals` (строка `1,0,1,...` по порядку колонок) |
| `garmin` | запись метрик за день | `date`, `text` |
| `read_diary` | чтение дневника | `limit`, `maxChars` |
| `read_habits` | чтение трекера | `limit`, `maxChars` |
| `read_garmin` | чтение метрик | `limit`, `maxChars` |
| `diag` | диагностика распознавания дат | — |

Ответы — текстом: `OK: ...` при успехе, `ERROR: ...` при ошибке.

Особенности реализации:
- запись привычек ищет строку с нужной датой; если её нет — вставляет новую
  после последней найденной даты, копирует форматирование строки-донора
  и принудительно ставит чекбоксы (`insertCheckboxes()`)
- даты в колонке C распознаются и как `Date`, и как текст `ДД.ММ.ГГГГ`
- строка с датой в дневнике оформляется заливкой `#93c47d`, жирным, вправо
- лист «гармин» создаётся автоматически при первой записи

### 2.3 Cloudflare Worker (прокси к Claude API)

| | |
|---|---|
| Имя | `moya-sistema-ai` |
| URL | `https://moya-sistema-ai.dzhunusov-482.workers.dev` |
| В гите | нет (код в веб-редакторе Cloudflare; копия — `cloudflare-worker.js`) |
| Секрет | `ANTHROPIC_API_KEY` (Settings → Variables and Secrets, тип Secret) |

Назначение: спрятать API-ключ от клиента. Принимает POST с телом запроса
к Anthropic Messages API, добавляет заголовки `x-api-key` и `anthropic-version`,
проксирует на `api.anthropic.com/v1/messages`, возвращает ответ с CORS-заголовками.

Модель: `claude-sonnet-5`. Аккаунт Anthropic — Tier 2 (после покупки кредитов на $40).

### 2.4 Garmin-бот

| | |
|---|---|
| Репозиторий | `github.com/zhunusov79/garmin-bot` |
| Запуск | GitHub Actions по cron: 02:05 UTC (07:05 Алматы) и 16:05 UTC (21:05) |
| Язык | Python 3.12 |

Файлы:
- `sync_garmin.py` — забирает метрики из Garmin Connect (библиотека
  `python-garminconnect` поверх `garth`, неофициальный API), делает upsert в Supabase
- `morning_brief.py` — читает последние 14 дней из Supabase, отправляет в Claude API,
  результат шлёт в Telegram; вызывает `push_rows(rows)` для синхронизации с таблицей
- `tracker_sync.py` — форматирует метрики в компактную строку и отправляет
  в лист «гармин» через вебхук Apps Script; можно запускать отдельно для бэкфила:
  `python3 tracker_sync.py [дней]`
- `alltime_report.py` — отчёт за всё время (запуск вручную)
- `supabase_schema.sql` — схема таблицы `garmin_daily`

Секреты в GitHub Actions: `GARMIN_TOKENS`, `SUPABASE_URL`,
`SUPABASE_SERVICE_ROLE_KEY`, `ANTHROPIC_API_KEY`, `TELEGRAM_BOT_TOKEN`,
`TELEGRAM_CHAT_ID`.

## 3. Потоки данных

**Запись дневника:** приложение → POST на Apps Script (`text`, `date`) →
строка(и) в лист «рефлексия».

**Запись привычек:** приложение → POST (`mode=habits`, `date`, `vals`) →
поиск/создание строки за дату → простановка чекбоксов.

**Синхронизация Garmin:** GitHub Actions → Garmin Connect → Supabase (upsert) →
`push_rows()` → Apps Script (`mode=garmin`) → лист «гармин».
Параллельно: Supabase → Claude API → Telegram (утренний бриф).

**Разбор ИИ-команды:** приложение читает три источника
(`read_diary`, `read_habits`, `read_garmin`) → для каждой включённой роли
формирует запрос с системным промптом роли + данными + репликами предыдущих ролей →
Cloudflare Worker → Claude API → ответ выводится в чат.
Роли опрашиваются последовательно; при ошибке — до трёх повторов с паузами.

## 4. Известные ограничения и долги

- **Apps Script и Worker не в системе контроля версий.** Единственные рабочие
  копии — в веб-редакторах Google и Cloudflare. Резервные копии нужно держать
  в репозитории и обновлять вручную.
- **Развёртывание Apps Script хрупкое.** Чтобы обновить код, нужно создать
  «Новую версию» в существующем развёртывании; создание нового развёртывания
  меняет URL и ломает связь с приложением. URL вшит в код приложения и бота.
- **Мультипользовательность отсутствует.** Вебхук и таблица зашиты в код.
  Версия для друзей (`index-dlya-druzey.html`) просит вебхук при первом запуске,
  но каждому нужно самостоятельно развернуть свою копию Apps Script.
- **Расходы на ИИ.** Один разбор шестью ролями — ориентировочно $0.15–0.25.
  Оплачивается ключом владельца.
- **Неофициальный API Garmin.** Библиотека может сломаться при изменениях
  на стороне Garmin; логин через личные учётные данные.
- **Нет тестов, нет CI для фронтенда, нет мониторинга ошибок.**
